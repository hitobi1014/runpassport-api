# 요청 처리 (request)

## 목적

사용자의 임의의 질문/요청 (코드와 직접 관련 없는 것 포함)을 받아 처리하는 범용 커맨드. **결과 (답변 내용 또는 작업 이후 결과)는 항상 `ai/response.md`에 작성한다.**

## 절차

1. 요청을 코드 생성으로 바로 옮기지 않는다. 먼저 관련 파일 (코드, `CLAUDE.md`,
   `ai/develop-ticket.md`, `note/기능명세.md` 등)을 찾아 읽고 실제 프로젝트 상태를 파악한 뒤 답변한다.
2. 요청이 애매하면: 진행 방향이 하나로 정리되면 가정을 명시하고 그 가정대로 진행한다. 방향이 여러 개로 갈리면 옵션을 제시하고 사용자에게 선택을 물어본다.
3. 요청이 여러 단계로 나뉘는 큰 작업이면 단계별로 나누고, 각 단계 완료 후 결과를 요약해서 보여준다. 되돌리기 어려운 작업 (파일 대량 수정, 외부 시스템 반영 등)이 포함되면 진행 전에 확인을 받는다.
4. 결과 (답변 내용 또는 작업 요약)는 `ai/response.md`에 작성한다. 이전 요청과 이어지는 작업이면 기존 내용에 이어서 갱신하고, 완전히 새로운 주제면 새로 작성해도 된다.

## 하지 않는 것

- 요청받지 않은 리팩토링/기능 추가를 덧붙이지 않는다.
- 노션 등 외부 시스템에 대한 쓰기 작업은 명시적으로 요청받은 경우에만 한다 (기본은 읽기 전용).
